# Nginx PHP Kubernetes CI/CD Project

## Project Overview

Automated deployment of an Nginx and PHP application on Kubernetes using GitHub Actions, Docker, Prometheus and Grafana.

## Technologies Used

- AWS EC2
- Amazon Linux 2023
- Docker
- Kubernetes
- Minikube
- GitHub Actions
- Docker Hub
- Prometheus
- Grafana

## Project Objectives

- Containerize an Nginx and PHP application.
- Deploy the application using Kubernetes.
- Automate application deployment using GitHub Actions.
- Implement Kubernetes Horizontal Pod Autoscaling.
- Monitor application and infrastructure metrics using Prometheus.
- Visualize monitoring data using Grafana.
